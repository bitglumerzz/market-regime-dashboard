# signal_lab — честная проверка «предсказывает ли признак направление»

Отвечает на главный вопрос сервиса: **угадывает ли модель направление цены чаще случайного — на данных, которых она не видела,
после комиссий и с учётом того, сколько вариантов мы перепробовали.**

```bash
pip install -r signal_lab/requirements.txt
python -m signal_lab.fetch --symbol BTCUSDT --tf 4h --since 2019-09-10     # реальные данные Binance (на своём компьютере)
python -m signal_lab.run --data data/BTCUSDT_4h.parquet --tf 4h --horizon 6  # → reports/signal_lab_BTCUSDT_4h_h6.md
python -m pytest signal_lab/tests -q                                         # проверка самой лаборатории на синтетике
```

## Модель v1 из исследования (`v1.py`)
По `docs/research/directional-edge-2026-09.md`: базовый трендовый сигнал (симметричный ансамбль Дончиана + TSMOM 4 нед.)
задаёт сторону, мета-модель (LightGBM/логит, изотоническая калибровка) решает, брать ли сделку; барьеры цель +2σ /
стоп −1.5σ / 48 ч; вход по матожиданию `p·цель − (1−p)·стоп − издержки > 0`. Ориентиры: базовый сигнал без фильтра,
«всегда long» с теми же барьерами, случайная сторона, buy & hold и long с размером по волатильности (H1).

```bash
python -m signal_lab.v1 --data data/BTCUSDT_4h.parquet --tf 4h --hours 48
python -m signal_lab.v1 --data data/BTCUSDT_4h.parquet --tf 4h --hours 48 --placebo   # контроль утечек
```

## Исследование directional edge (09.2026): гипотезы H1–H10, реестр, holdout
Итог — `reports/edge_summary.md`: ни одна из 263 спецификаций не прошла гейт, в том числе на holdout.

```bash
python -m signal_lab.fetch --symbol BTCUSDT --tf 4h --extras          # + oi, dvol, dxy (с лагом H.10), hmm_p_* (forward filter)
python -m signal_lab.h1 --data data/BTCUSDT_spot_1d.parquet           # H1 размер по волатильности
python -m signal_lab.h2 --data data/BTCUSDT_spot_1d.parquet           # H2 реплика Zarattini (--placebo 200 — перестановки)
python -m signal_lab.v1 --data data/BTCUSDT_4h.parquet --tf 4h --hours 48 [--placebo] [--conformal 0.2] [--drop F5_]
python -m signal_lab.ablation --data data/BTCUSDT_4h.parquet --drop X_hmm --hypothesis H10   # H4/H10; --gate — H7
python -m signal_lab.h6 --data data/BTCUSDT_4h.parquet                # H6 режим фандинга
python -m signal_lab.holdout --dry-run                                # holdout открывается один раз: --i-understand-this-runs-once
```
- **Реестр испытаний** `reports/trials.csv` (`registry.py`): каждый прогон дописывает строки, N для DSR берётся отсюда.
- **Holdout** с 01.04.2025: `registry.before_holdout` отрезает его до построения признаков и меток; открыть можно
  один раз (`open_holdout`, отметка в реестре). Уже открыт 30.09.2026.
- Отчёты по гипотезам — `docs/research/experiments/H*.md`, включая отрицательные.

## Что делает
1. **Признаки** (`features.py`, все каузальные): моментум 1–28 дней, моментум с поправкой на волатильность, отрыв от средней,
   пересечение средних, положение в канале Дончиана, краткосрочный разворот, RSI, режим волатильности, аномальный объём,
   дисбаланс агрессивных покупок/продаж, ставка финансирования и её z-оценка, изменение открытого интереса.
2. **Однофакторные тесты:** направление связи выбирается на обучении, попадание проверяется на следующем блоке;
   поправка Бенджамини–Хохберга на множественное тестирование.
3. **Модель** (логистическая регрессия и LightGBM) на всех признаках с правилом **«воздержаться при низкой уверенности»**.
4. **Честность:** walk-forward с расширяющимся окном, purge = горизонт, только непересекающиеся сделки (правильные p-value),
   комиссия за вход и выход, **Deflated Sharpe Ratio** с учётом числа испробованных вариантов.

## Как читать отчёт
- Попадание **52–56%** на непересекающихся сделках — это уже сильный результат. **Выше 60%** — почти наверняка утечка данных.
- Смотрите не на попадание, а на **среднюю сделку после комиссий** и **DSR**: 55% на 189 сделках при DSR 0.24 —
  это шум (именно такой результат лаборатория выдаёт на чистом случайном блуждании, см. тесты).
- **Гейт:** DSR > 0.95, средняя сделка > 0 после комиссий, ≥ 100 непересекающихся сделок. Не прошли — не продаём.

## Проверено на синтетике (`tests/`, 29 тестов)
- новые ряды (OI, DVOL, DXY, HMM) не заглядывают вперёд и учитывают задержку публикации; реестр append-only,
  holdout открывается один раз; H2 — стоп-храповик и исполнение со следующего дня; H6 — эпизоды не пересекаются;
  конформное воздержание только убирает сделки;
- случайное блуждание → значимых признаков нет, гейт не пройден;
- встроенный моментум → лаборатория его находит, модель проходит гейт;
- изменение «будущих» данных не меняет признаки прошлого (нет заглядывания вперёд);
- PBO ≈ 0.5 на шуме и низкий при реальном преимуществе; PSR/MinTRL, бутстрап, барьеры, правило матожидания, Келли;
- v1: на случайном блуждании гейт закрыт, на плацебо мета-модель «не помогает», на тренде сигнал находится и бьёт «всегда long».

- подсаженная утечка (признак «знает» будущее) даёт предупреждение «Подозрение на утечку» в отчёте;
- вход по открытию следующего бара (сигнал доходит до подписчика с задержкой) и веса уникальности пересекающихся сделок;
- PSR, DSR, MinTRL и PBO совпадают с независимой реализацией `purgedcv` (MIT) до 3-го знака.

Уроки аудита 40+ открытых проектов (`docs/research/oss-trading-ml-audit-2026-09.md`) закреплены в `tests/test_audit_lessons.py`.

Главный урок синтетики: на отрезке, где рынок просто рос, «всегда long» выглядит гениально (DSR 0.99).
Поэтому модель обязана обыгрывать «всегда long», а не ноль.
