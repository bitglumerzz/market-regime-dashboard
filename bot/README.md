# @regime_ai_bot — платный доступ к сигналам ИИ-советника

Telegram-бот на aiogram 3: знакомит с сервисом, продаёт доступ за **Telegram Stars**, ведёт подписки
и рассылает подписчикам сигналы, которые присылает **ваша локальная модель** через защищённый HTTP API.

```
   Mac с моделью ──HTTPS + HMAC──▶  бот (VPS)  ──▶  подписчики в личке  (+ закрытый канал)
   client/push_signal.py            regime_bot        итоги сделок → честная статистика
```

## Что умеет

**Для пользователя**
- `/start` — приветствие и меню: как работает модель, пример сигнала, тарифы, статистика, мой доступ, вопросы, пригласить друга, поддержка.
- Перед оплатой — отдельное согласие на обработку ПДн (152-ФЗ, ссылка `PRIVACY_URL`) и честное предупреждение о рисках
  с кнопкой «Понимаю риски и принимаю» (оба факта сохраняются). `/delete_me` — удаление данных по запросу.
- Тарифы в Stars: **1 месяц с автопродлением** (нативная Stars-подписка), **3 месяца**, **12 месяцев** — цены в `.env`.
- Оплата прямо в Telegram → доступ открывается мгновенно; повторная доставка платежа не зачтётся дважды.
- «Мой доступ»: срок, автопродление (отключается кнопкой), ссылка в закрытый канал, последние сигналы.
- Сигналы приходят в личку; итог сделки — ответом на исходный сигнал.
- Публичная статистика: все закрытые сделки, прибыльные **и убыточные**.
- Рефералка: `t.me/regime_ai_bot?start=ref_<id>` — пригласившему +7 дней после первой оплаты друга.
- Метки рекламных кампаний: `t.me/regime_ai_bot?start=src_reels1` — видно в `/stats`, какой ролик приводит покупателей.
- Напоминания за 3 дня и за 1 день до конца доступа; по окончании — удаление из канала и предложение продлить.
- Обязательные для оплат команды `/terms` и `/paysupport`.

**Для админа** (`ADMIN_IDS`): `/stats` (пользователи, подписки, выручка ⭐, конверсия по источникам), `/grant`,
`/revoke`, `/refund <charge_id>` (возврат звёзд + отзыв доступа), `/broadcast subs|all` (ответом на сообщение), `/testsignal`.

## Запуск за 5 минут

```bash
cd bot
python3 -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env        # вставьте BOT_TOKEN, ADMIN_IDS, SIGNAL_API_SECRET
python -m regime_bot        # MODE=polling: бот работает, API сигналов слушает :8081
```

В @BotFather ничего включать не нужно: Stars работают без платёжного провайдера, команды и описание бот выставит сам.
Для закрытого канала: создайте приватный канал, добавьте бота админом (права «приглашать» и «банить»),
впишите `CHANNEL_ID` (вида `-100…`).

**Продакшен:** VPS + `docker compose up -d --build` (база в `./data`, делайте бэкап). Для API сигналов нужен HTTPS:
Caddy перед портом 8081 или Cloudflare Tunnel. Режим `MODE=webhook` + `WEBHOOK_BASE=https://ваш-домен` — Telegram
будет слать апдейты на `/tg/webhook` того же сервера.

## Как модель присылает сигналы

Контракт API — `regime_bot/api.py`, готовый клиент без зависимостей — `client/push_signal.py`:

```python
from push_signal import push_signal, close_signal   # REGIME_API_URL и REGIME_API_SECRET — в окружении
push_signal({"ext_id": "btc-4h-20261001-1", "asset": "BTC/USDT", "timeframe": "4H", "side": "LONG",
             "entry": 64250, "stop": 63100, "targets": [66000, 67900], "confidence": 0.78,
             "regime": "бычий тренд", "horizon": "1–3 дня", "rationale": "Коротко — почему."})
close_signal("btc-4h-20261001-1", status="tp", result_pct=5.7)     # tp | sl | closed | cancelled
```

- Подпись: `X-Regime-Timestamp` + `X-Regime-Signature = hex(HMAC-SHA256(secret, ts + "." + body))`, окно 5 минут.
- `ext_id` делает отправку идемпотентной: повтор после сетевой ошибки не создаст дубль.
- Бот проверяет логику цен (у LONG стоп ниже входа, цели выше) и отклоняет кривые сигналы с кодом 422.
- `result_pct` — от цены входа до выхода, без плеча; `cancelled` в статистику не идёт.

## Тесты

```bash
pip install -r requirements-dev.txt && python -m pytest -q
```
17 тестов: логика доступа и продлений, Stars-подписки, рефералы, напоминания, HMAC, валидация сигналов,
HTTP API, клиент `push_signal.py` против живого сервера и **сквозной сценарий через Dispatcher**
(`/start` → согласие на ПДн → риски → тарифы → счёт → pre-checkout с подменой цены → оплата → доступ → уведомление админу).

## Важно

- Бот позиционирует сигналы как **аналитику, а не индивидуальные инвестиционные рекомендации**, показывает
  предупреждение о рисках до оплаты и полную статистику. Правовой статус платных сигналов в РФ (39-ФЗ,
  инвестсоветники) и маркировку рекламы (38-ФЗ, erid) обсудите с юристом — см. `docs/research` и промты.
- Звёзды выводятся через Fragment после периода удержания Telegram; Telegram берёт комиссию — учитывайте в цене.
- Токен бота и `SIGNAL_API_SECRET` держите только в `.env`; при утечке токена — `/revoke` в @BotFather.
