## Правила честности (нарушать нельзя)
- **Реестр испытаний.** Заведи `reports/trials.csv`: каждая проверенная спецификация (набор признаков, барьеры, порог,
  горизонт, актив, модель) — строка с датой и результатом. Их общее число — N для DSR. Ничего не удалять.
- **Отрицательные результаты сохраняются** в `docs/research/experiments/Hx-*.md` так же подробно, как положительные.
- **Holdout.** Период с 01.04.2025 по сегодня не трогай, пока спецификация не заморожена. Открыть его можно один раз —
  финальной проверкой. Запиши в реестр, когда открыл.
- Не подбирай параметры под тест. Меняешь что-то после того, как увидел результат — это новое испытание.
- Каждый новый признак — с тестом на отсутствие заглядывания вперёд (как `test_features_do_not_look_ahead`)
  и с учётом задержки публикации данных (ETF-потоки T+1, COT — пятница за вторник, фандинг — в момент начисления).
- Прогоняй `--placebo` для каждой финальной конфигурации. Если на плацебо «улучшение» есть — ищи утечку.
- Никогда не пиши «гарантированно», «точность 90 %», «доходность X %» в отчётах, которые могут попасть к клиентам.

## Шаг 2. Обязательные гипотезы (до любого продакшена)
Для каждой — отдельный отчёт в `reports/` и запись в реестр.
- **H1. Управление размером по волатильности.** `python -m signal_lab.v1 --data … --tf 1d` → блок H1 в отчёте.
  Успех: Sharpe выше buy & hold и просадка ниже на всех 5-летних окнах. Это базовый слой риск-менеджмента, а не «преимущество».
- **H2. Ансамбль пробоев Дончиана (реплика Zarattini).** Реализуй точную версию: окна {5,10,20,30,60,90,150,250,360} дней,
  трейлинг-стоп по середине канала, размер 0.25/σ_90d, порог ребаланса 20 %, 10 б.п. Сначала период до 03.2025, потом
  holdout 04.2025–сегодня. Успех: net Sharpe ≥ 0.8 на holdout и DSR > 0.95 (N ≥ 27: окна × варианты стопа). Ожидай цифры
  ниже статьи — это нормально.
- **H3. Мета-модель улучшает базовый трендовый сигнал.** `python -m signal_lab.v1 --data data/BTCUSDT_4h.parquet --tf 4h
  --hours 48` (плюс `--hours 24`, `--hours 72` — это 3 испытания) и то же для ETH, затем `--placebo`.
  Успех по отчёту: гейт пройден (DSR > 0.95, PBO < 0.2, нижняя граница 95 % ДИ > 0, ≥ 100 сделок, лучше «всегда long»),
  H3 подтверждена, ≥ 2 сигнала в месяц, на плацебо H3 не подтверждается.
