# Промт 06 — Второй платёжный рельс (только после консультации с юристом)

---

Ты — backend-разработчик Telegram-ботов. Репозиторий `market-regime-dashboard`, ветка `claude/modest-tesla-bcavni`,
папка `bot/` (aiogram 3.31, оплата Stars уже работает). Прочитай `bot/README.md`, `bot/regime_bot/access.py`,
`bot/regime_bot/db.py`, `bot/regime_bot/handlers/payments.py`, `bot/tests/` и раздел 5 отчёта
`docs/research/regime-ai-stack-2026-09.md`.

**Контекст:** правила Telegram требуют продавать цифровой доступ внутри бота за Stars. Но Stars дороги для
пользователя из РФ и выводятся только в TON. Юрист одобрил (впиши, какой вариант): **Tribute** (подписки по картам РФ,
выплаты в ₽/€) и/или **Crypto Pay** (@CryptoBot, USDT/TON).

## Что сделать
1. Общий слой: функция `grant_access(tg_id, plan, source, external_id, until|days)` поверх существующей
   `db.extend_access`; в `payments` добавить колонку `provider` (stars | tribute | cryptopay) с миграцией.
   Идемпотентность по `(provider, external_id)`.
2. **Tribute:** ссылка на подписку из бота (кнопка на экране тарифов, пометка «оплата картой»), вебхук на
   `POST /api/v1/tribute` с проверкой подписи (формат подписи перепроверь по официальной документации — отчёт не смог
   подтвердить hex/base64), события: новая подписка, продление, отмена → `grant_access`/снятие автопродления.
3. **Crypto Pay:** создание счёта через API (фиатный номинал), вебхук `invoice_paid` с проверкой подписи
   (HMAC-SHA256 от токена), зачисление доступа на срок тарифа.
4. Экран «Мой доступ» показывает источник оплаты; `/stats` — выручку по провайдерам; отмена/возврат для каждого.
5. Тесты по образцу `bot/tests/test_signals_api.py`: верная подпись → доступ; неверная → 401; повторный вебхук не
   продлевает дважды; сквозной тест экрана тарифов.

## Ограничения
- Stars остаётся основным способом внутри Telegram. Внешние способы — только если это разрешено текущими правилами
  Telegram для вашего случая: перепроверь раздел о цифровых товарах в документации Bot API/ToS на дату работы.
- Не упоминать оплату криптой в рекламе. Никаких ключей/токенов в коде и чате.

## Готово, когда
- Все три способа оплаты дают одинаковый доступ, тесты зелёные, README дополнен, изменения запушены.
