# Промт 05 — ИИ-судья на Claude 5.5 и русский комментарий локальной LLM

---

Ты — инженер LLM-систем. Репозиторий `market-regime-dashboard`, ветка `claude/modest-tesla-bcavni`, мой Mac.
Прочитай `claude_rescore.py`, `claude_call_log.py`, `wave_ai.py` (сейчас там `claude-opus-4-7`), `requirements.txt`
(`anthropic>=0.30.0`) и раздел 3.3 отчёта `docs/research/regime-ai-stack-2026-09.md`.

**Цель:** (1) обновить ИИ-судью на актуальные модели Claude с контролем стоимости; (2) генерировать короткий
понятный русский комментарий к сигналу локальной моделью, чтобы не зависеть от облака.

## Часть A — Claude как судья
1. Используй встроенный скилл Claude Code для миграции (`/claude-api migrate`), чтобы перейти на актуальный SDK
   и модели: `claude-opus-5-5` для сложного арбитража гипотез, `claude-sonnet-5-5` — для массового рескоринга.
   Проверь по скиллу актуальные цены и правила, не полагайся на память.
2. Prompt caching для длинного системного промта с чек-листом (проверь `cache_read_input_tokens > 0` в тесте);
   ночной пересчёт — через Message Batches (−50%), с обработкой отказов/ошибок по каждому элементу.
3. Структурированный вывод (JSON-схема оценок) вместо парсинга текста.
4. Лимит расходов в долларах в сутки в `claude_call_log.py`: при превышении — судья пропускается, сигнал помечается
   «без ИИ-оценки», а не блокируется.
5. Оценка судьи — это **признак** для модели из промта 03 (проходит ту же калибровку), а не финальное решение.

## Часть B — Локальный русский комментарий
1. Установи Ollama (стабильная ветка) или mlx-lm; сравни 2–3 открытые модели, хорошо пишущие по-русски
   (кандидаты проверь сам на ollama.com/library и Hugging Face на дату запуска — отчёт не смог подтвердить размеры).
2. `commentary.py`: на вход — структурированный сигнал и признаки; на выход — JSON `{rationale: str}` ≤ 600 символов,
   деловой тон, без обещаний прибыли, без слов «гарантия/точно/100%»; числа в тексте проверяются против входных
   (если модель выдумала цифру — отбросить и сгенерировать заново или использовать шаблон).
3. Бенчмарк на 30 исторических сигналах: качество русского текста, скорость на моём Mac, доля отбраковки.
4. Фолбэк: если локальная модель недоступна — шаблонный текст из режима/структуры.

## Готово, когда
- Судья работает на новых моделях, кэш и лимит расходов покрыты тестами, стоимость за сутки видна в логе.
- `commentary.py` выдаёт проверенный русский текст для `rationale` в сигналах промта 04; отчёт бенчмарка приложен.
