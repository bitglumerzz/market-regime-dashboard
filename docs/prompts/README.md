# Промты для десктопного Claude Code — REGIME AI

То, что нельзя сделать из облака (ваш Mac, VPS, реальный токен бота, деньги, юрист), разбито на
самодостаточные промты. Каждый можно вставить в новую сессию Claude Code на вашем компьютере —
в нём есть контекст, цель, ограничения и критерии готовности.

**Источник решений:** [`docs/research/regime-ai-stack-2026-09.md`](../research/regime-ai-stack-2026-09.md) —
глубокое исследование (9 агентов на Fable 5.1, каждая область перепроверена отдельным агентом-скептиком).
Раздел 8 отчёта — что подтвердить не удалось: такие места промты просят перепроверить локально.

## Как запускать

1. Склонируйте репозиторий и переключитесь на рабочую ветку:
   ```bash
   git clone https://github.com/bitglumerzz/market-regime-dashboard && cd market-regime-dashboard
   git checkout claude/modest-tesla-bcavni
   ```
2. Откройте Claude Code в папке репозитория. Для больших промтов (02–05) лучше Fable 5.1 или Opus 5.5;
   для объёмной работы можно добавить в конец промта слово `ultracode` — Claude разобьёт задачу на агентов.
3. Вставьте содержимое файла промта целиком. Секреты (токены, ключи) **не вставляйте в чат** —
   Claude сам попросит вписать их в `.env`.

## Главный принцип (зашит во все промты)

Продавать доступ к сигналам можно только после **гейта качества** из отчёта (раздел 4):
DSR > 0.95, PBO < 0.2, ожидание сделки после комиссий > 0 на всех тестовых путях и не хуже на
≥300 закрытых live-событиях. До этого — бесплатная бета и накопление честной статистики.
