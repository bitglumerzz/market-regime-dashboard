# H2 — ансамбль пробоев Дончиана (реплика Zarattini, Pagani, Barbon 2025)

**Вердикт: отклонена** на однократной проверке holdout (01.04.2025 – 29.09.2026): Sharpe 0.06 (BTC) и 0.62 (ETH)
при критерии ≥ 0.8, DSR ≈ 0. Как слой снижения риска (волатильность 10–11 %, просадка 14–16 %) стратегия работает;
как источник доходности на этом периоде — нет. Код: `signal_lab/h2.py`. Отчёты: `reports/H2_*_spot_1d.md` (v1) и `reports/H2_*_spot_1d_v0.md`.
Реестр: испытания 3–122 (`reports/trials.csv`, hypothesis = H2).

## Спецификация
Точная реплика по PDF статьи (сверка — `docs/research/directional-edge-2026-09-verification.md`):
канал по закрытиям, включая сегодняшнее; вход при Close = n-дневный максимум; выход при Close ≤ стопа; стоп-храповик
TS_{t+1} = max(TS_t, Mid_t), начальный стоп = середина канала; вес модели min(0.25/σ90, 2.0); ансамбль — среднее
9 окон {5,10,20,30,60,90,150,250,360}; порог 20 % только для изменений из-за σ; 10 б.п. × |Δw|.
Наши допущения там, где статья молчит: простые доходности и √365 для σ, выход раньше входа, порог относительно
текущего веса ансамбля. Данные: Binance spot BTCUSDT/ETHUSDT (с 17.08.2017), а не агрегат CoinMarketCap с 2015.

## Хронология испытаний (честно)
1. **v0** (испытания 3–62): первая реализация по описанию в отчёте directional-edge — канал по n предыдущим закрытиям,
   кэп веса 1x, порог 20 % на все изменения, σ по лог-доходностям. Прогнана и зарегистрирована **до** сверки со статьёй.
2. Сверка со статьёй (шаг 0) нашла три расхождения: кэп 200 %, канал включает сегодня, порог только для σ.
3. **v1** (испытания 63–122): точная версия. Результаты v0 остаются в реестре и входят в N.

В обе волны входят 9 одиночных окон × 3 варианта выхода (храповик по середине, середина без храповика,
нижняя граница) + 3 ансамбля — всего 30 испытаний на актив на волну (требование N ≥ 27 выполнено).

Наблюдения:
- Кэп 2x почти не связывает: σ̂ BTC/ETH редко ниже 12.5 % годовых, поэтому v0 и v1 почти равны.
- Одиночные окна 20–60 дней по Sharpe сопоставимы с ансамблем или выше (BTC n=30: 1.42 в v0). Выбирать лучшее
  окно по этой таблице нельзя: это ровно тот отбор на истории, от которого защищает DSR. Спецификация зафиксирована
  как ансамбль.
- Длинные окна (150–360) слабее: Sharpe 0.8–1.0.
- **DSR ансамбля ниже 0.95 уже на периоде разработки** (0.81 BTC, 0.58 ETH). При N ≥ 90 и ~2400 дневных наблюдениях
  Sharpe 1.3 статистически не отличим от «лучшего из многих случайных». Для holdout (≈ 18 мес., ≈ 550 дней)
  пройти DSR > 0.95 почти невозможно даже при Sharpe ≈ 1.5: ожидаем «не выполнен» по критерию DSR
  при возможном выполнении критерия Sharpe ≥ 0.8.

## Плацебо (перестановочный тест, до holdout)
Дневные доходности перемешаны 200 раз (серийная зависимость разрушена, распределение сохранено), та же спецификация:
BTC — настоящий Sharpe 1.29 против медианы 0.63 и 95-го перцентиля 1.07 (p = 0.015); ETH — 1.08 против 0.45 / 0.90
(p = 0.010). Тренд-эффект на периоде разработки не объясняется одним лишь положительным дрейфом. Отчёты:
`reports/H2_*_spot_1d_placebo.md`.
