# Промо-ролик ИИ-советника (Studio)

Вертикальный ролик 1080×1920, 48 с, 30 fps — для Reels / Shorts / TikTok / Telegram.
Всё сделано кодом (HTML + CSS + Canvas), рендер покадровый, поэтому результат детерминирован.

Версия 3 собрана по покадровым разборам Студии (`bitglumerzz/studio`, ветка `studio/motion-research`,
`research/skillry-boards/dale-vaz-879074.md` и `madhav-xo-524440.md`) и по кривым из `anima/приёмы`.

## Сцены
| Время | Сцена | Откуда приём |
|---|---|---|
| 0–2.9 с | **Хук.** Гигантская красная японская свеча падает на весь экран, камера летит вниз за ценой, тряска, «−12,4%». Стоп-кадр: всё серое, кроме красной свечи, золотая линия ИИ-анализа, «А если бы ты знал *заранее?*». Перемотка ◀◀, свечи схлопываются в точку | свой хук: удар → вопрос → перемотка |
| 2.9–11 с | Точка → линия → окно со свечным графиком → вокруг собирается терминал (вотчлист, ИИ-анализ, стакан, позиции). Камера ныряет на разных масштабах: общий план → ИИ-панель (78%, LONG) → общий план → нырок в последнюю свечу | dale-vaz: «start with a single dot… windows… zoom into and out at multiple scales» |
| 11–13.6 с | Нырок в экран до RGB-субпикселей, «ЧТО ВНУТРИ?» | dale-vaz, кадры 14–16 с (пиксельная сетка) |
| 13.6–23.6 с | Презентация ИИ-модели: терминал с компиляцией → созвездие нейросети → орбиты «6 слоёв анализа» → замок из частиц «Риск под контролем» → дуга планеты «24/7» → сетка «1 чёткий сигнал» → конвейер «Данные → решение» → световой росчерк → логотип модели с курсивным слоганом. Склейки ровно в долю 120 BPM | madhav-xo, покадрово |
| 23.6–27.3 с | Снова терминал, прибыль по позициям растёт; камера отъезжает, пока терминал не станет точкой среди звёзд; наезд сквозь звёзды | dale-vaz: «desktop look like a point in space» |
| 27.3–36 с | Из точки вырастает телефон (лёжа → поворот вертикально): сигнал LONG, «Принять решение», «✓ Ордер исполнен за 4.2 мс», прибыль по сделке | dale-vaz: мобильный экран + «Order placed in 4.2 ms» |
| 36–41.7 с | «Решения — на основе данных. Время — для жизни.» → «Жизнь на полную» | — |
| 41.7–48.3 с | Призыв в Telegram-бот, дисклеймер | — |

## Смена бренда и бота
Параметры задаются в URL / флагах рендера (текст сам ужимается, если имя длинное):
```bash
NODE_PATH=$(npm root -g) node render.js --brandA MYBRAND --brandB AI --model "MYBRAND CORE" --bot @my_bot
```

## Предпросмотр и рендер
- Предпросмотр: открыть `index.html` в браузере (клик — пауза, `?t=15` — начать с 15 с).
- Кадры для проверки: `node render.js --stills 3,11,17.6,31`
- Видео: `node render.js` → `promo.mp4` (нужны Playwright + ffmpeg; путь к ffmpeg можно задать через `FFMPEG=`).

## Звук и рекламная нарезка
Звук синтезируется кодом (`sound.py`), без сэмплов и стоков, поэтому права на трек только ваши.
Стиль — phonk-house 120 BPM: дисторшн-808 с глайдами, фонк-ковбелл, хлопки, дроби хай-хэтов, суперсо-пэды,
сайдчейн под бочку, параллельный «эксайтер». Сетка: сильная доля ровно на 13.6 с (дроп на презентации модели).

Саунд-дизайн по кадру: удар и срыв 808 вниз вместе со свечой (0 с) → остановка ленты на стоп-кадре (0.6 с) →
гул и сканер → перемотка задом наперёд (1.6 с) → «пинг» точки (2.8 с) → вжух линии и щелчки окон →
грув (5.6 с) → ускоряющаяся дробь, райзер и обрыв (10.9–13.45 с) → ДРОП (13.6 с) с ударом на каждой склейке →
лазер и удар логотипа (20.4/20.6 с) → фильтр закрывается при отъезде в космос → дроп на телефоне (27.6 с) →
клик и «дзынь» ордера (32.6 с) → светлый мажор «Жизнь на полную» (35.6 с) → финальный дроп на Telegram (41.6 с).

```bash
./build.sh      # promo_sound.mp4 (48 с) + ad_18s.mp4 (18.6 с), громкость −14 LUFS / пик −1 dB
```

Рекламная нарезка (`AD_CUTS` в `sound.py`), все стыки в долю: хук 0–3.3 → терминал собирается 3.3–7.1 →
ИИ 78 % · LONG → «6 слоёв анализа» / «Риск под контролем» → росчерк и логотип модели → клик «Принять решение»
и «Ордер исполнен» → Telegram-бот с дисклеймером.

## Важно
Дисклеймер о рисках в финальной сцене не убирайте: реклама финансовых инструментов без предупреждения
о рисках и с обещанием дохода нарушает правила рекламы (закон «О рекламе», правила площадок).
