# Промо-ролик ИИ-советника (Studio)

Вертикальный ролик 1080×1920, 42.6 с, 30 fps — для Reels / Shorts / TikTok / Telegram.
Всё сделано кодом (HTML + CSS + Canvas), рендер покадровый, поэтому результат детерминирован.

## Сцены
| Время | Сцена | Приём |
|---|---|---|
| 0–4 с | «Рынок не ждёт. Каждая секунда — это решение.» | кинетическая типографика с масками, светящаяся линия цены |
| 4–8 с | «Шум. Эмоции. Догадки.» | «штамп»-типографика, хаос свечей, зачёркивание, схлопывание в точку |
| 8–12 с | Появление бренда ИИ-советника | световое ядро, вращающиеся HUD-кольца, частицы, трекинг букв |
| 12–21.7 с | Презентация ИИ-модели | имя «расшифровывается» из глифов, данные текут по нейросети (входы → слои → выход LONG · 78%), плитки со счётчиками |
| 21.7–31 с | Как принимается решение | 3D-стеклянный телефон: свечи, скан ИИ, режим рынка / волны / сентимент, сигнал LONG, нажатие «Принять решение», рост P&L |
| 31–36.6 с | «Решения — на основе данных. Время — для жизни.» | рассвет над горизонтом, барабан слов → «Жизнь на полную» |
| 36.6–42.6 с | Призыв в Telegram-бот | иконка TG, список, пульсирующая кнопка с @ботом, дисклеймер |

## Смена бренда и бота
Параметры задаются в URL / флагах рендера (текст сам ужимается, если имя длинное):
```bash
NODE_PATH=$(npm root -g) node render.js --brandA MYBRAND --brandB AI --model "MYBRAND CORE" --bot @my_bot
```

## Предпросмотр и рендер
- Предпросмотр: открыть `index.html` в браузере (клик — пауза, `?t=15` — начать с 15 с).
- Кадры для проверки: `node render.js --stills 3,11,17.6,31`
- Видео: `node render.js` → `promo.mp4` (нужны Playwright + ffmpeg; путь к ffmpeg можно задать через `FFMPEG=`).

## Звук (добавляется при монтаже)
Биты для саунд-дизайна: 0.3 с — удар/рисер; 4.2 / 4.7 / 5.2 с — три «стампа»; 7.9 с — вспышка/whoosh;
9.1 с — появление логотипа; 12.5–13.5 с — цифровой «декод» имени модели; 15.5 с — запуск потока данных;
17.4 с — акцент на выходе модели; 19.2–20.5 с — тики счётчиков; 21.9 с — whoosh телефона;
27.05 с — клик по кнопке; 30.6 с — смена настроения (тёплый пэд); 33.6–35.5 с — тики барабана слов;
36.6 с — финальный акцент на CTA.

## Важно
Дисклеймер о рисках в финальной сцене не убирайте: реклама финансовых инструментов без предупреждения
о рисках и с обещанием дохода нарушает правила рекламы (закон «О рекламе», правила площадок).
