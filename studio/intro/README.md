# Интро аккаунта X — 15 с

1920×1080, 30 fps. Собрано на приёмах из библиотеки Студии (`bitglumerzz/studio` → `anima/приёмы`):

| Время | Сцена | Приёмы |
|---|---|---|
| 0–3.9 с | Знак собирается из 6 полос, рядом выезжает имя и @handle | `E-15` сборка знака (задержки 0.04…0.29 с, 0.5 с, `cubic-bezier(.16,1,.3,1)`), `E-21` строки из-под маски (118 %, 0.85 с), каскад 140 мс, заливка акцента |
| 3.5–4.6 с | Золотая шторка «ПРОФИЛЬ» | `A-23` clip-path шторка, `cubic-bezier(.76,0,.24,1)` |
| 4–9.4 с | Профиль X «оживает»: обложка въезжает 5 полосами, аватар (единственная пружина), имя, био, клик «Подписаться» | каскад 80 мс, `A-14` наезд, стекло со световой рамкой `A-16`/`D-28`, пружина `(.68,-.6,.32,1.6)` |
| 9.1–12.5 с | О чём аккаунт: заголовок, 32 столбика, 3 стеклянные карточки | `B-06` 32 столбика шагом 30 мс, `B-07` «прогноз» на 28 %, `E-22` заливка акцента |
| 12.3–15 с | Финал: знак, имя с бликом, пилюля 𝕏 @handle, Telegram | `A-08` блик по тексту (3 с/проход), `B-16` замыкающий каскад |

## Свои логотип и обложка
Положите файлы в `assets/`:
- `assets/logo.png` — квадратный логотип (лучше PNG с прозрачностью): собирается теми же 6 полосами и становится аватаром;
- `assets/cover.jpg` — обложка X 1500×500.

Без них подставляются фирменный знак и нарисованная обложка.

```bash
cd studio
NODE_PATH=$(npm root -g) node promo/render.js --page intro/index.html \
  --query "name=Имя аккаунта&handle=@handle&tg=@bot&joined=2024&bio=Строка 1|Строка 2"
```
Предпросмотр: открыть `intro/index.html` в браузере (клик — пауза).
