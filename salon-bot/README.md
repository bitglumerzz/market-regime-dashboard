# Telegram-бот — цифровой администратор студии наращивания ресниц (DIKIDI)

Бот записывает клиентов на услуги, показывает свободное время и напоминает о визите.
Все записи создаются **прямо в журнале DIKIDI Business**, поэтому администратор видит их
в приложении DIKIDI, а бот видит записи, сделанные в DIKIDI вручную или через онлайн-запись DIKIDI.

## Что умеет

**Для клиента**
- 💅 Запись: услуга → мастер (или «любой свободный») → день → свободное время → имя и телефон → подтверждение.
  Свободные окна берутся из DIKIDI в момент выбора, а перед созданием записи слот проверяется ещё раз.
- 📅 «Мои записи»: список предстоящих визитов с кнопкой отмены (отмена уходит в DIKIDI).
- 🔔 Напоминания за 24 часа и за 2 часа до визита.
- ℹ️ Если администратор отменил или перенёс запись в DIKIDI, бот сообщит об этом клиенту.
- 💰 Услуги и цены, 📍 контакты, 💬 вопрос администратору.
- Постоянным клиентам не нужно заново вводить имя и телефон.

**Для администратора**
- Уведомления о новых записях, отменах и вопросах (в личку или в рабочую группу).
- `/today`, `/tomorrow`, `/week` — расписание из DIKIDI.
- Ответ клиенту: ответьте (reply) на пересланный вопрос, и бот передаст ответ.
- `/admin` — список команд.

## Как устроена синхронизация с DIKIDI

У DIKIDI нет открытого публичного API для записи. Бот использует неофициальный SDK
[`dikidi-api-client`](https://pypi.org/project/dikidi-api-client/), который работает от имени
аккаунта владельца/администратора салона (как веб-версия DIKIDI Business):

| Действие в боте | Что происходит в DIKIDI |
|---|---|
| Список услуг и мастеров | читается из каталога компании |
| Свободное время | считается по графикам мастеров и существующим записям DIKIDI |
| Подтверждение записи | создаётся запись в журнале DIKIDI |
| Отмена клиентом | запись удаляется в DIKIDI |
| Раз в 5 минут | бот сверяет свои записи с DIKIDI (отмены и переносы) |

⚠️ **Важно понимать риски:** SDK неофициальный, и DIKIDI может изменить свой внутренний API.
Весь код работы с DIKIDI собран в одном файле — `bot/backends/dikidi.py`; если что-то сломается,
править нужно только его. Перед запуском обязательно выполните проверку (см. ниже).
Если хотите официальную интеграцию — запросите API-доступ у своего менеджера/поддержки DIKIDI;
тогда достаточно будет переписать тот же `dikidi.py`.

## Установка

Нужен Python **3.13+** (этого требует SDK DIKIDI; для тестового режима хватит 3.11).

```bash
cd salon-bot
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env    # и заполните .env
```

1. Создайте бота у [@BotFather](https://t.me/BotFather) → `BOT_TOKEN`.
2. Узнайте свой Telegram ID у [@userinfobot](https://t.me/userinfobot) → `ADMIN_IDS`.
   Для уведомлений в рабочую группу добавьте бота в группу и укажите её ID в `ADMIN_CHAT_ID`.
3. Укажите логин/пароль DIKIDI Business (`DIKIDI_PHONE`, `DIKIDI_PASSWORD`) и ID компании
   (`DIKIDI_COMPANY` — число из ссылки на вашу страницу, например `https://dikidi.ru/1234567`).
   Лучше завести в DIKIDI отдельного сотрудника-администратора для бота.
4. В DIKIDI должны быть заполнены услуги (с длительностью), мастера и их графики работы.

## Проверка подключения к DIKIDI

```bash
python -m bot.check_dikidi
```

Скрипт ничего не меняет — только выводит услуги, мастеров, свободные окна на завтра и записи
на неделю. Сверьте с тем, что видите в DIKIDI. Затем сделайте одну тестовую запись через бота
и убедитесь, что она появилась в журнале DIKIDI.

## Запуск

```bash
python -m bot.main
```

Для постоянной работы запускайте на сервере (VPS) через `systemd`, `docker` или `pm2`.

### Тестовый режим без DIKIDI

Поставьте `BACKEND=local` — услуги и мастера возьмутся из `catalog.json`, записи сохранятся
в локальную базу `data/bot.sqlite3`. Удобно, чтобы посмотреть бота «вживую» до подключения DIKIDI.

## Структура

```
bot/
  main.py              — запуск
  config.py            — настройки из .env
  handlers/booking.py  — сценарий записи
  handlers/common.py   — меню клиента, мои записи, отмена, вопрос админу
  handlers/admin.py    — команды администратора
  background.py        — напоминания и синхронизация с DIKIDI
  backends/dikidi.py   — работа с DIKIDI (единственное место интеграции)
  backends/local.py    — тестовая система записи
  storage.py           — локальная база бота (клиенты Telegram, напоминания)
  check_dikidi.py      — проверка подключения
tests/                 — тесты (pytest)
```
